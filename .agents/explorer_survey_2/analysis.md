## 3. Mocking Manim Binary Execution via `subprocess.run()`

### 3.1 Requirement
Acceptance criteria requires:
> *"The test suite MUST use a mock Python script to simulate the Manim binary, explicitly verifying that the node correctly maps visual cues to CLI flags and successfully deletes all temporary directories upon both success and simulated failure."*

### 3.2 Mock Binary Construction Strategy
To test subprocess execution without relying on an installed Manim binary or C++ dependencies:
1. **Executable Mock Python Script**: In pytest's `tmp_path`, create `mock_manim.py` (or a bin wrapper) containing a shebang (`#!/usr/bin/env python3`).
2. **Behavior Control**:
   - Parses arguments passed via `sys.argv[1:]`.
   - Appends received CLI flags to an audit log file (`mock_manim_args.json`).
   - If `--fail` flag is present or `SIMULATE_MANIM_FAILURE=1` in environment, writes to `sys.stderr` and exits with code `1`.
   - On success, creates a dummy output video file (e.g., `output.mp4`) at the path specified by `-o` or `--media_dir` flags, and exits with code `0`.
3. **Execution**: Pass `manim_bin=str(script_path)` to `AnimationGeneratorNode` or set `PATH`/`MANIM_BINARY` environment variables.

### 3.3 Reference Implementation of Mock Manim Script Fixture

```python
import sys
import os
import json
from pathlib import Path
import pytest

@pytest.fixture
def mock_manim_script(tmp_path: Path):
    """
    Creates an executable mock Python script that simulates the Manim CLI binary.
    """
    bin_dir = tmp_path / "bin"
    bin_dir.mkdir(parents=True, exist_ok=True)
    script_path = bin_dir / "mock_manim.py"
    log_path = tmp_path / "manim_cli_args.json"

    script_content = f"""#!/usr/bin/env python3
import sys
import json
from pathlib import Path

args = sys.argv[1:]
log_path = Path({repr(str(log_path))})

# Log CLI arguments for test assertion
with open(log_path, "a") as f:
    f.write(json.dumps(args) + "\\n")

# Simulated failure trigger
if "--fail" in args or "FAIL_RENDER" in args:
    sys.stderr.write("Error: Manim scene render exception\\n")
    sys.exit(1)

# Look for output directory / file in CLI args
for i, arg in enumerate(args):
    if arg in ("-o", "--output_file") and i + 1 < len(args):
        out_file = Path(args[i + 1])
        out_file.parent.mkdir(parents=True, exist_ok=True)
        out_file.write_bytes(b"MOCK_MANIM_MP4_VIDEO_DATA")
    elif arg == "--media_dir" and i + 1 < len(args):
        media_dir = Path(args[i + 1])
        media_dir.mkdir(parents=True, exist_ok=True)
        (media_dir / "rendered_scene.mp4").write_bytes(b"MOCK_MANIM_MP4_VIDEO_DATA")

sys.exit(0)
"""
    script_path.write_text(script_content)
    script_path.chmod(0o755)  # Make executable
    return script_path, log_path
```

## 4. Visual Cues to CLI Flags Mapping Test Strategy

### 4.1 Input Schema Structure (`VisualCue` in `src/models/script.py`)
Each `VisualCue` object contains:
- `cue_id: str` (e.g. `"cue_01"`)
- `animation_type: str` (e.g. `"array_highlight"`, `"tree_traversal"`, `"code_scene"`, `"title_card"`)
- `description: str`
- `timestamp_seconds: float`
- `parameters: Dict[str, Any]` (e.g. `{"array": [1, 2], "quality": "medium"}`)

### 4.2 Mapping Contract Rules
`AnimationGeneratorNode` must map `VisualCue` attributes to Manim CLI flags:
| Visual Cue Parameter / Config | Manim CLI Flag | Target Scene / Option |
|-------------------------------|----------------|----------------------|
| Quality: `"low"` / default    | `-ql` or `--quality l` | Low resolution (480p15) fast render |
| Quality: `"medium"`           | `-qm` or `--quality m` | Medium resolution (720p30) |
| Quality: `"high"`             | `-qh` or `--quality h` | High resolution (1080p60) |
| `animation_type: "array_highlight"` | `ArrayScene` | `src/animation/scenes/array_scene.py` |
| `animation_type: "tree_traversal"`  | `TreeScene`  | `src/animation/scenes/tree_scene.py` |
| `animation_type: "code_scene"`      | `CodeScene`  | `src/animation/scenes/code_scene.py` |
| Output Directory              | `--media_dir <path>` | Temporary render folder |
| Output File                   | `-o <filename>` | Destination `.mp4` file |

### 4.3 Test Verification Scenarios
1. **Quality Flag Mapping**: Verify `-ql` is passed when quality config is `"low"`, `-qh` when `"high"`.
2. **Scene Resolution**: Verify correct scene module and class name are passed based on `animation_type`.
3. **Parameters Injection**: Verify scene parameters are correctly encoded (e.g., passed as JSON string or environment variable).
4. **Unknown Animation Type Handling**: Verify `PipelineStageError` or `ValueError` is raised when `animation_type` is unrecognized.

## 5. Cleanup Verification: Temporary Directories & File Descriptors

### 5.1 Temporary Directory Cleanup Mechanism
During rendering, `AnimationGeneratorNode` must generate intermediate assets inside an isolated temporary directory (e.g., `tempfile.TemporaryDirectory()` or `tmp_path / "render_tmp_XXXX"`).

To guarantee zero storage leakage across renders, cleanup must be enforced using a `try...finally` block:
```python
temp_dir = Path(tempfile.mkdtemp(prefix="manim_render_"))
try:
    # Execute Manim render subprocess
    ...
finally:
    if temp_dir.exists():
        shutil.rmtree(temp_dir)
```

### 5.2 Test Assertions for Directory Cleanup
1. **Success Case**:
   - Capture `temp_dir` path during execution (via mock or logger hook).
   - Assert `Path(temp_dir).exists() is False` after `node.execute()` finishes successfully.
2. **Failure Case (Simulated Error)**:
   - Trigger Manim subprocess non-zero exit code (`1`).
   - Catch `AnimationError` or `PipelineStageError`.
   - Assert `Path(temp_dir).exists() is False` after exception is caught.

### 5.3 File Descriptor Leak Prevention & Test Method
Subprocess execution can leak file handles if standard output/error streams are opened without context management.
- **Node Requirement**: Node must use `subprocess.run(..., capture_output=True, text=True)` or explicitly close pipes.
- **FD Cleanup Test Helper**:
  ```python
  import os

  def get_open_fd_count() -> int:
      """Returns count of open file descriptors for current process."""
      try:
          return len(os.listdir("/proc/self/fd"))
      except FileNotFoundError:
          return 0  # Fallback for systems without /proc

  def test_file_descriptor_cleanup_on_success_and_failure(node, ledger, run_id):
      initial_fds = get_open_fd_count()
      
      # Run execution
      node.execute(run_id=run_id, ledger=ledger)
      
      final_fds = get_open_fd_count()
      assert final_fds == initial_fds, f"FD leak detected: {final_fds} > {initial_fds}"
  ```

## 8. Summary of Recommendations for Implementation Phase

1. **Node Inheritance**: `AnimationGeneratorNode` must inherit from `src.core.workflow.node.Node` and implement `.name` (returning `"animation_generator"`) and `.execute(run_id, ledger)`.
2. **Subprocess Invocation**: Use `subprocess.run(cmd, capture_output=True, text=True, check=True)` wrapped inside a `try...finally` block for deterministic temporary directory removal.
3. **Artifact Registration**: Integrate with `ArtifactManager` or register generated `.mp4` file details in the node's output payload returned to `StateLedger`.
4. **Mock Execution Support**: Allow overriding `manim_binary` path in node constructor (defaulting to `"manim"` system command) to enable zero-dependency unit testing via python script mocking.
